# Учебные модули Chunki

Откройте **Админка → Учебные модули → Импорт JSON**. Вставьте JSON, нажмите **Проверить JSON**, затем **Импортировать**. Проверка покажет ошибки и какие модули будут созданы или обновлены.

```json
{
  "modules": [
    {
      "id": "a1-introductions",
      "title": "Знакомство и рассказ о себе",
      "description": "Поздороваться, представиться и поддержать короткий разговор.",
      "level": "A1",
      "position": 10,
      "type": "core",
      "topicIds": [
        "a1-core-functions-greetings",
        "a1-core-functions-personal-info",
        "a1-verb-to-be"
      ]
    },
    {
      "id": "b1-conversation-practice",
      "title": "Поддерживаем разговор",
      "description": "Практикуемся начинать разговор, выражать мнение и проверять понимание.",
      "level": "B1",
      "position": 20,
      "type": "supplementary",
      "topicIds": [
        "b1-core-functions-conversation-edges",
        "b1-opinions",
        "b1-core-functions-checking-understanding"
      ]
    }
  ]
}
```

- `id` — стабильный ключ модуля из строчных латинских букв, цифр и дефисов. Совпадающий ID обновляет поля модуля и заменяет его список тем.
- `position` — целое число от 0. В админке модули сортируются по CEFR, затем по этому числу.
- `type` — `core` для основного модуля или `supplementary` для дополнительного.
- `topicIds` — существующие ID учебных целей из каталога CEFR, в нужном порядке. Внутри модуля ID уникальны. Одну тему можно привязать к нескольким модулям.
- `level` — уровень из каталога Chunki. Темы должны относиться к тому же базовому уровню, например A2 и A2+ относятся к одному уровню.

Ошибки в любом модуле останавливают весь импорт. Записи с ID, которых нет в файле, сохраняются. Удаление модуля удаляет только его связи с темами. Материалы уроков и пользовательский прогресс хранятся отдельно.
